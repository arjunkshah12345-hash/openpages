# Design Context

## Users
Builders who want an open ChatGPT Space / OpenAI Pages alternative — humans + agents sharing memory without blowing the context bill.

## Brand Personality
Warm paper, quiet confidence, editorial restraint. Room to think — not a dashboard.

## Aesthetic Direction
**OpenPages v2 landing (canonical):** warm paper `#fbfbf9`, ink `#20201e`, muted `#72726c`, rule `#e4e4de`, green `#158568` / `#087b60` for life signals and brand accents. Primary CTAs are ink pills on paper (not green fills). SuperCompress stays blue `#0566ff` for SC-only callouts. Soft radii, sparse sections, product stage that mirrors the real Spaces chrome. Geist body. Landing film + workspace mock are part of the brand.

## Design Principles
1. **One composition** — first viewport is brand + one idea + one CTA group, not a feature grid.
2. **Platform matches landing** — Spaces shell uses the same paper/ink/rule tokens as `/`.
3. **SuperCompress is infrastructure** — visible in context savings, never the whole visual identity.
4. **Anti:** purple gradients, cream+serif terracotta, ChatGPT cold white as primary, icon-card feature grids.
