# OpenPages — asset provenance

- OpenPages mark: unchanged original from this repository, `public/favicon.svg`.
- Geist variable font: copied from this app's bundled Next.js font asset.
- Motion graphics: original editable SVG/CSS/GSAP choreography for this film.
- Product UI: editorial reconstruction of the repository's Space, Pages, and agent interfaces.
- Demo workspace text and answers: illustrative content, not a recorded model run.
- Original score: `scripts/score.py`, 120 BPM, 32 seconds, stereo 48 kHz.
- Sound design: original synthesized paper ticks, air transitions, low impacts,
  compression grains, and a three-note brand signature. No stock samples.
- Mastering: FFmpeg loudness normalization, target −16 LUFS, −1.2 dBTP ceiling.
- GSAP 3.14.2: locally frozen distribution from jsDelivr; no render-time network dependency.
- Kinetic type rail: uses the masked fixed-slot technique from the installed
  HyperFrames `kinetic-type-swap` component, adapted to the OpenPages type system.

No OpenAI marks or assets used. OpenAI is a visual direction, not an affiliation.
